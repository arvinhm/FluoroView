Install FluoroView

FluoroView 4 is a preview on the v4 branch. It runs as a local engine that serves the studio to your browser; setting it up takes four commands.

Requirements

  • Git, to get the source.
  • Python 3.11 or newer with uv, for the engine.
  • Node.js 20 or newer, to build the studio once.
  • A browser with WebGL 2: current Chrome, Edge, Firefox or Safari.

  1. Get the source

    git clone -b v4 https://github.com/arvinhm/FluoroView.git

  2. Build the studio

    This builds the browser interface into the engine package. Repeat it after each update.

    cd FluoroView/studio && npm ci && npm run build

  3. Install the engine

    cd ../engine && uv sync

  4. Open a scan

    The studio opens in your browser. The first time a scan is opened, FluoroView reads it once to build its zoom levels; later opens reuse them. 

    uv run fluoroview /path/to/scan.tif

Try the example data

The repository includes a five-channel example scan in example_data. Start FluoroView without a file, choose File › Open…, select the five channel files together and press Open 5 files as channels. 

uv run fluoroview

Options

OptionMeaning
IMAGEA scan to open at start-up (optional).
--port NPort to listen on. By default a free port is chosen.
--no-browserDo not open a browser window; open the printed address yourself.
--cache-dir PATHWhere zoom levels are kept. fluoroview --help shows the default.
--cache-limit-gb NLargest size of that cache, in GB (default 20).
--host ADDRESSInterface to listen on (default 127.0.0.1).

Keep the default host. The engine can open any file this computer can read for whoever holds its token, so it is meant to listen only on your own machine.

Update

From the FluoroView folder:

git pull
cd studio && npm ci && npm run build
cd ../engine && uv sync

Status

FluoroView 4 is under active development, and is developed and tested on macOS. Session files (.fv) record their format version.
